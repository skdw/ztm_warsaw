# 🤝 Contributing

- **Ideas, bug reports and pull requests are welcome.** How to run the checks and open a pull request is in [CONTRIBUTING.md](https://github.com/solarssk/ztm_warsaw/blob/main/CONTRIBUTING.md).
- **Rules for changes** (what must not change, how tests are written, how reviews work) are in [AGENTS.md](https://github.com/solarssk/ztm_warsaw/blob/main/AGENTS.md); they apply to people and to AI coding agents alike.
- **Security reports:** see [SECURITY.md](https://github.com/solarssk/ztm_warsaw/blob/main/SECURITY.md). Do not report a vulnerability in a public issue.
- **Conduct:** [CODE_OF_CONDUCT.md](https://github.com/solarssk/ztm_warsaw/blob/main/CODE_OF_CONDUCT.md).

## Editing this wiki

The wiki is published from the `docs/wiki/` folder of the repository when a change lands on `main`. Edit the files there in a pull request; a change made in the wiki's own web interface is overwritten by the next publish. The pages are checked in CI (every page exists, every link resolves).
