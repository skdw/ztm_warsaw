# 1.2.0: nowe API miasta, przystanki pod jedną linią i pojazdy na mapie

**Stare API Warszawy przestało działać 21 października 2026.** Ta wersja jest przygotowana na nowe: dostaje się do niego przez darmowy token, a przy okazji integracja zyskała sporo nowych możliwości. Dziękujemy za cierpliwość wszystkim, którzy zgłaszali problem! 💙

## ⚠️ Zanim zaktualizujesz

- **Potrzebujesz tokenu.** Klucz do starego API już nie działa, więc linia ze starym kluczem nie dostanie nowych rozkładów. Token wygenerujesz za darmo na [dane.um.warszawa.pl/pl/key-api](https://dane.um.warszawa.pl/pl/key-api) i wkleisz w powiadomieniu w **Ustawienia → Naprawy**. Jeden token wystarczy dla wszystkich linii.
- **Przystanki są pogrupowane według linii.** Każda linia to teraz jeden wpis, a jej przystanki są pod nim. Twoje sensory zachowują nazwy, ID i ustawienia. Jeśli jakaś automatyzacja albo karta wskazuje na stare *urządzenie*, trzeba je wybrać na nowo. **Wstecz do 1.1.4 nie ma powrotu**, więc zrób najpierw kopię zapasową.
- **Potrzebny jest Home Assistant 2026.1 lub nowszy.** Na starszym HACS nie zaproponuje aktualizacji i zostaniesz na 1.1.4.
- **Każdy sensor pokazuje następny odjazd i trzy kolejne**, więc wybór „liczby odjazdów” zniknął.
- **Dwa wpisy dla tego samego przystanku i linii?** Drugi nigdy nie miał sensora. Usuń go, gdy Naprawy o tym powiedzą.

## ✨ Co nowego

- **Prostsza konfiguracja**: wpisujesz fragment nazwy przystanku, wybierasz słupek i linię, która naprawdę tam staje. Skróty miasta też są rozumiane.
- **Przystanki i pojazdy na mapie**: każdy słupek to jeden pin, a linia może pokazywać swoje pojazdy: z kierunkiem, brygadą, trasą, przewoźnikiem, modelem, prędkością i więcej.
- **Odległość autobusu** (opcjonalnie): do automatyzacji typu „autobus jest 500 m stąd”.
- **Czas dojścia na przystanek**: sensor pomija odjazdy, na które już nie zdążysz.
- **Kalendarz odjazdów** oraz **kolejne odjazdy jako osobne encje** (obie rzeczy domyślnie wyłączone).
- **Status słowami**: „dziś kursuje”, „na dziś odjazdów już nie ma”, „dziś nie kursuje”, „trwa aktualizacja rozkładów”.
- **Powiadomienie, gdy miasto milczy przez kilka godzin**, bo unieważniony token wygląda dokładnie tak.
- **Osiem języków** (nowe tłumaczenia są maszynowe, poprawki mile widziane), diagnostyka do zgłoszeń błędów (bez Twojego klucza) i podpisany zip z wydaniem.

Pełna lista zmian jest poniżej. Coś nie działa? Zajrzyj do [Troubleshooting](https://github.com/solarssk/ztm_warsaw/wiki/4.-Troubleshooting) albo załóż zgłoszenie. Nigdy nie wklejaj tam klucza ani tokenu.

# 1.2.0: the City's new API, stops under one line and vehicles on the map

**The City of Warsaw's old API stopped working on 21 October 2026.** This version is ready for the new one: it signs in with a free token, and it brings a lot of new features along the way. Thank you to everyone who reported the problem! 💙

## ⚠️ Before you update

- **You need a token.** A key for the old API no longer works, so a line with an old key gets no new timetables. Get a free token at [dane.um.warszawa.pl/pl/key-api](https://dane.um.warszawa.pl/pl/key-api) and paste it in the notice under **Settings → Repairs**. One token is enough for all your lines.
- **Stops are grouped by line.** Each line is now one entry with its stops under it. Your sensors keep their names, IDs and settings. If an automation or card points at the old *device*, choose it again. **There is no way back to 1.1.4**, so take a backup first.
- **Home Assistant 2026.1 or newer is required.** On an older one HACS will not offer the update and you stay on 1.1.4.
- **Every sensor lists the next departure and the three after it**, so the “number of departures” choice is gone.
- **Two entries for the same stop and line?** The second one never had a sensor. Remove it when Repairs tells you.

## ✨ What's new

- **A friendlier setup**: type a part of the stop's name, pick the pole and a line that really stops there. The City's abbreviations are understood too.
- **Stops and vehicles on the map**: every stop pole is one pin, and a line can show its vehicles with the destination, brigade, route, operator, model, speed and more.
- **Distance to the bus** (optional): for an automation like “the bus is 500 m away”.
- **A walking time for every stop**: the sensor skips the departures you could no longer catch.
- **A calendar of departures** and **the following departures as entities of their own** (both off by default).
- **A status in words**: “runs today”, “no more departures today”, “does not run today”, “timetables are being updated”.
- **A notice when the City stays silent for hours**, because a revoked token looks exactly like that.
- **Eight languages** (the new translations are machine-made, corrections welcome), diagnostics for bug reports (your key is hidden) and a signed zip with each release.
